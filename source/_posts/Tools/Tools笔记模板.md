## 二级分类写法示例

上面的 front-matter 中 `categories` 写了两级：`Tools / BurpSuite`，
即"大类 / 子类"，子类你后续可以按需补充，比如：

- Tools / BurpSuite
- Tools / Yakit
- Tools / Frida

Hexo 会自动生成对应的分类层级页面。
