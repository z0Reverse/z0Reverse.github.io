1. **密钥大小**：RSA密钥大小通常为1024或2048位。2048位以上更安全，但会增加加密和解密的时间。

2. **性能**：RSA适合加解密少量数据。通常与对称加密结合，使用RSA加密对称密钥，再用对称密钥加密实际数据。

3. **异常处理**：在实际应用中，需进行详细的异常处理，包括`NoSuchAlgorithmException`, `InvalidKeyException`, `BadPaddingException` 等。

4. **填充使用**：在实际应用中，建议使用RSA/ECB/OAEPWithSHA-256AndMGF1Padding这样的填充方案，来抵抗已知的攻击方式。

- **KeyFactory**：用于从已有的密钥数据生成密钥对象。它更像是一个“解析器”，专注于将编码的密钥格式转换成Java的密钥对象。

用于加解密场景(公钥加密，私钥解密)

```java
public static KeyPair generateKeyPair() throws NoSuchAlgorithmException {
        KeyPairGenerator keyPairGen = KeyPairGenerator.getInstance("RSA");
        keyPairGen.initialize(2048); // 设置密钥大小，常用2048位
        return keyPairGen.generateKeyPair();
    }

public static void main(String[] args) {

        String originalText = "Hello, RSA!";

public static String encrypt(String plainText, PublicKey publicKey) throws Exception {
    Cipher encryptCipher = Cipher.getInstance("RSA");
    encryptCipher.init(Cipher.ENCRYPT_MODE, publicKey);

    byte[] cipherText = encryptCipher.doFinal(plainText.getBytes());

    return Base64.getEncoder().encodeToString(cipherText);
}

public static String decrypt(String cipherText, PrivateKey privateKey) throws Exception {
    Cipher decryptCipher = Cipher.getInstance("RSA");
    decryptCipher.init(Cipher.DECRYPT_MODE, privateKey);

    byte[] bytes = Base64.getDecoder().decode(cipherText);

    return new String(decryptCipher.doFinal(bytes));
}
```

验签场景

```java
public static String sign(String data, PrivateKey privateKey) throws Exception {
    Signature rsaSignature = Signature.getInstance("SHA256withRSA");
    rsaSignature.initSign(privateKey);
    rsaSignature.update(data.getBytes());

    byte[] signature = rsaSignature.sign();
    return Base64.getEncoder().encodeToString(signature);
}

// 验证签名
public static boolean verify(String data, String signature, PublicKey publicKey) throws Exception {
    Signature rsaSignature = Signature.getInstance("SHA256withRSA");
    rsaSignature.initVerify(publicKey);
    rsaSignature.update(data.getBytes());

    byte[] signatureBytes = Base64.getDecoder().decode(signature);

    return rsaSignature.verify(signatureBytes);
}
```
