# AWS

```
GET /phone-cms-hz-test-2/../1743227373509_upload_11083607398742938245.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Date=20250331T083710Z&X-Amz-SignedHeaders=host&X-Amz-Expires=86400&X-Amz-Credential=LTAI5tQZxXDqhtGtrqYMAtHG%2F20250331%2Fcn-hangzhou%2Fs3%2Faws4_request&X-Amz-Signature=2493d06c031e73c2978fc4163396119a2aa01a80873a30b618cd2e5357efc66f HTTP/1.1
Host: feedback-cn-t.tcliot.com
Accept-Encoding: gzip, deflate, br
User-Agent: okhttp/4.12.0
Connection: close
```

1. **X-Amz-Algorithm=AWS4-HMAC-SHA256**:

    - 指定用于签名请求的算法，在这里是AWS使用的HMAC-SHA256算法。
    - 使用 `AWS Signature Version 4`。这个算法通过一系列步骤来进行请求签名，包括对请求内容、相关的HTTP头、请求路径，以及其他参数进行加密签名，确保请求的完整性和发起人的真实身份。
2. **X-Amz-Date=20250331T083710Z**:

    - 指定请求的日期和时间。格式是ISO 8601，表示2025年3月31日08:37:10 UTC。
3. **X-Amz-SignedHeaders=host**:

    - 指定在计算签名时使用的HTTP头。在这里，只有`host`头部被指定用于签名。
4. **X-Amz-Expires=86400**:

    - 设置URL的有效期，以秒为单位。86400秒等于24小时，表示该URL自生成后24小时内有效。
5. **X-Amz-Credential=LTAI5tQZxXDqhtGtrqYMAtHG/20250331/cn-hangzhou/s3/aws4_request**:

    - 包括IAM用户的访问密钥ID和请求的范围（日期、区域、服务）。这里的字符串表示S3服务在`cn-hangzhou`区域的凭证。
    - 由于这个URL只包含访问密钥ID（而非秘钥本身），并且签名是时间限制的，单凭此信息无法单独用于访问其他AWS资源。风险主要在于此URL被泄露后，在其有效期内可被不当使用来访问指定的S3资源
6. **X-Amz-Signature=2493d06c031e73c2978fc4163396119a2aa01a80873a30b618cd2e5357efc66f**:

    - 这是用指定的算法签名的数据，用于验证请求的真实性和完整性。
    - `X-Amz-Signature` 通过HMAC-SHA256算法来生成，是对以下内容的加密签名： HTTP请求方法（如GET),请求的URI和查询参数, 请求的日期时间（X-Amz-Date）, HTTP头（如 X-Amz-SignedHeaders指定的）, 其他安全性相关参数,这些信息被压缩为字符串，对该字符串进行HMAC签名生成最终签名。任何对URL信息的更改（如时间、头部、路径等）均会导致签名无效。
