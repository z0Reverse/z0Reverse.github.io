## 关于本站

这里是「我的安全笔记」，用于记录个人安全技术学习过程中的笔记与总结。

## 分类体系

- **WebSecurity** — Web 安全漏洞、渗透测试、靶机通关笔记（二级类：SQL注入、越权、文件上传、SSRF...）
- **JavaCodeSecurity** — Java 代码审计、反序列化、组件漏洞分析（二级类：反序列化、表达式注入、组件漏洞...）
- **AndroidReverse** — 安卓逆向、Frida/Xposed、脱壳与抓包（二级类：脱壳、Hook、抓包...）
- **Tools** — 常用安全工具的使用技巧与配置（二级类：BurpSuite、Yakit、iptables...）

> 二级分类无需提前注册，写笔记时在 categories 下多写一行即可自动生成。
> 标签用于横向串联跨类关键词（如：提权、ROOT、复现）。
